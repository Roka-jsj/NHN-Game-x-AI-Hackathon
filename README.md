## 어떤 게임인가

**한 화면 레인 배틀.** Age of War 계보. 화면 왼쪽이 내 기지, 오른쪽이 적 기지다.
아래 버튼 줄에서 병력을 사면 걸어 나가 싸운다. 먼저 상대 기지를 부수면 이긴다.

```
유닛 6종 1~6   진화 7   포탑 8   해일 9   화살비 0   증원 R
```

그리고 **아래에서 물이 차오른다.** 유닛도 기지도 잠긴다.
Age of War 류의 고질병은 교착인데, 물이 그걸 푼다 — **버티는 쪽이 먼저 죽는다.**
「차오른다」는 배경이 아니라 마감 시계다.

### 상성이 돈다 — 하나로 전부를 이길 수 없다

```
        검사 → 창병 → 기병 → 궁수 → 검사
                       기병 → 투석기
                       궁수 → 거인
```

화살표 쪽이 이긴다. 배수는 2.5배다. 표를 손으로 쓰면 반드시 어긋나므로
**규칙에서 생성한다** (`config.js` 의 `COUNTER`).

거인과 투석기는 **이기는 상대가 없다.** 벽과 공성으로 값을 치른다.
이건 표의 결함이 아니라 성질이고, 시작 화면이 그렇게 적어 둔다.

| | 값 | 사거리 | 성질 |
|---|---|---|---|
| 검사 | 32 | 22 | 균형 |
| 창병 | 29 | 38 | 기병을 잡는다 |
| 궁수 | 20 | 128 | 가장 싸다. 대신 물렁하고 근접에 잡힌다 |
| 기병 | 33 | 24 | 가장 빠르다 |
| 거인 | 56 | 26 | 체력 165 |
| 투석기 | 45 | 300 | **유닛을 안 본다. 기지만 친다** |

**최소 사거리**가 있다. 궁수는 44, 투석기는 180 안쪽으로 붙으면 못 쏜다 —
활을 당길 공간이 없고 투석기는 코앞에 못 쏜다. 배수로는 "닿기 전에 죽는 것"을
못 뒤집으므로, 삼각형의 실패한 두 변을 **구조로** 돌렸다.
못 쏘면 물러난다(`U_BACKSTEP`). 얼어붙게 두면 그게 곧 병목이 된다 —
실측으로 내 병력의 21.2%가 그 상태였다.

### 진화 — 언제 누르느냐가 전부다

시대는 다섯이다. **돌 · 청동 · 강철 · 화약 · 기계.**
경험치가 차면 진화할 수 있고, 진화하면 **살아 있는 병력이 통째로 새 시대로 승격된다.**

대가가 있다. 승격되는 1.25초 동안 **움직이지도 때리지도 못한다.**
그래서 진화는 "돈 되면 누르는 것"이 아니라 **언제 누를지**가 된다 —
전선이 맞붙은 순간에 올리면 그 자리에서 전멸한다.

양쪽 모두에게 적용된다. **적이 진화하는 순간은 기회다.**

### 특수기 넷

| | 무엇 |
|---|---|
| 포탑 | 기지 위 대포. 두 단계까지 올린다 |
| 해일 | 전선을 쓸고 기절시킨다. **전선에서 멀수록 덜 맞는다** |
| 화살비 | 세 구역 중 하나에 쏟아진다 |
| 증원 | 병력을 공짜로 세운다 |

적도 같은 것을 쓴다. **적이 쓰기 전에 예고가 뜬다** — 하늘에 위협색 띠가 깔리고,
경고 삼각형과 스킬 이름과 남은 시간 막대가 뜨고, 화살비는 실제 착탄 구역을,
해일은 밀려올 방향과 거리를 미리 그린다. 그 창이 유일한 반응 기회다.

예고가 필요했던 이유는 측정에서 나왔다. 적이 **증원 → 화살비 → 해일**을 3.2초 안에
연달아 쓰면 내 병력 16기가 0이 됐다. 플레이어 패배 6건 전부가 이 연타였다.
스킬 사이에 전역 간격을 두고(최소 0.6초 → 6.7초), 예고 창을 열고,
해일 감쇠를 **전선 기준**으로 다시 걸어 전멸을 판당 1.8회 → 0.8회로 낮췄다.

### 별자리 — 그 판의 하늘

전투마다 12별자리 중 하나가 걸린다. **양쪽에 걸린다.**

한쪽에만 주면 매 전투 공짜 버프가 되어 난이도가 무너진다. 그리고 양쪽에 걸려야
**아는 쪽이 이긴다** — 궁수자리면 궁수가 세고 황소자리면 거인이 싸다.
적 사령관은 제 성격대로만 뽑으므로, 하늘을 읽고 구성을 바꾸는 쪽이 이득을 본다.
운이 아니라 **판마다 정답이 바뀌는 것**이 이 기능의 값어치다.

```
양 선봉    양쪽 다 기병 두 기로 시작한다      게 만조    해일 쿨다운 절반. 대신 물이 빨리 찬다
황소 우직  거인과 투석기가 30% 싸다           사자 포효  진화해도 재무장 경직이 없다
쌍둥이 쌍생 세 번째 소환마다 한 기 더          처녀 정련  진화 경험치 20% 적다
천칭 균형  상성 우위 피해가 더 아프다          전갈 독아  포탑이 두 배로 자주 쏜다
궁수 명궁  궁수·투석기 사거리 25% 길다        염소 행군  행군 속도가 더 빠르다
물병 범람  스킬 피해 40% 크다                 물고기 유영 아무도 익사하지 않는다
```

**판정에 `Math.random()` 을 쓰지 않는다.** 전투 번호와 씨앗을 섞은 결정론 해시다.
같은 판을 다시 돌리면 같은 별자리가 나온다. 계측기는 `game.forceZodiac(i)` 로 고정한다.

### 원정 — 사령관 다섯

판 하나가 아니라 여정이다. 이기면 다음 사령관, 지면 원정 종료.

| | 사령관 | 성격 | 한 마디 |
|---|---|---|---|
| 1 | 무리 | 물량형 | 수는 그 자체로 무기다. |
| 2 | 쇄도 | 돌격형 | 생각할 시간을 주지 않겠다. |
| 3 | 금고 | 축재형 | 너는 지금 쓰고, 나는 나중에 쏟는다. |
| 4 | 성벽 | 농성형 | 네가 지칠 때까지 나는 서 있다. |
| 5 | 거울 | 균형형 | 나는 네가 무엇을 좋아하는지 이미 안다. |

**순서는 가르치는 순서다.** 물량형이 가장 읽기 쉽고(상성만 알면 이긴다),
균형형이 마지막이다 — 균형형은 플레이어를 읽고 따라오므로 도배가 안 통한다.

사령관은 **디렉터의 다섯 프로파일에 얼굴을 준 것**이다.
디렉터가 플레이어를 새로 판정하면 사령관이 제 성격대로 도발한다.

`localStorage` 가 금지이므로 원정은 **세션 메모리에만 산다.** 새로고침하면 사라진다.
이건 제약이지 버그가 아니다 — 어디에도 "저장됨"이라고 쓰지 않는다.

### 난이도는 곡선이지 상수가 아니다

첫 전투는 이기라고 있고 마지막 전투는 지는 것이 기본값이다.
나쁜 난이도(체력·수입만 올리기)를 피하려고 축을 셋으로 나눴다.

| 축 | 무엇을 정하는가 |
|---|---|
| `STAGE_HP_MUL` | **판 길이만** 정한다. 난이도가 아니다 |
| `STAGE_DIFF` | 적 수입·사령관 공격성. 실수의 대가 |
| `STAGE_WATER_MUL` | 수위 속도 = 마감 시계 |

`STAGE_HP_MUL` 은 **내려가는 사다리다. 오타가 아니다.** 뒤 전투는 병력·시대·스킬
때문에 이미 저절로 길다(실측 전투1 17.5초 vs 전투5 98.5초). 같은 길이를 만들려면
앞에 많이 주고 뒤에 적게 줘야 한다.

### 행군 — "답답하다"의 정체는 걷는 시간이었다

실측: 소환한 유닛이 처음 교전하기까지 중앙값 **14.1초**.
전장 폭이 730px인데 검사 속도가 46이라 횡단에 15.9초가 걸린다.
누른 결과를 14초 뒤에 보면 인과가 안 느껴진다.

속도 상수를 올리면 **전투까지 같이 빨라져** 난이도 곡선이 흔들린다.
그래서 **아무도 없을 때만** 뛰게 했다 — 시야 안에 적이 없으면 행군한다.
전투 속도는 1px도 안 바뀌고 빈 벌판을 건너는 시간만 줄어든다.

부수 효과가 하나 더 있다. 이 게임의 전선이 가운데서 굳는 이유는 **수비 측 증원이
언제나 더 빨리 도착하기 때문**이다(걷는 거리가 짧다). 행군이 그 되먹임을 깬다.

### 색은 밝기로 진영을, 색상으로 병종을 말한다

여섯 색 규율로 시작했는데 세 가지를 못 갚아서 팔레트를 늘렸다.

- **유닛 6종이 각자의 색을 갖는다.** 진영은 여전히 **밝기**로 읽는다 —
  아군은 밝은 몸에 어두운 테, 적군은 가라앉은 몸에 유닛색 밝은 테.
  색상은 양쪽이 공유하므로 병종과 진영이 서로를 안 가린다
- **위협색은 적 예고와 적 스킬에만 쓴다.** 문제는 어두움이 아니라 같음이었으니
  배타성으로 푼다. 저 분홍이 뜨면 무조건 적이 뭔가 한다는 뜻이다
- **시대마다 하늘·지층·협곡·기지의 색조가 바뀐다.** 전부 구운 배경 안이라
  프레임당 비용이 0이고, 유닛보다 뒤에 깔려 유닛색을 안 덮는다

칠할 때 램프(알파)가 아니라 **미리 섞은 불투명색**을 쓴다. 알파를 쓰면 유닛이
겹치는 순간 아래층이 비쳐 밝아져서 **뭉칠수록 색이 사라진다** — 효과가 제일
필요한 자리에서 정확히 무너지는 방식이다.

### 배경음악 — 오디오 파일 0개인데 층으로 쌓인다

박자를 내려면 보통 박마다 노드를 만들어야 하는데, 그건 「루프 안에서 노드를
만들지 않는다」와 정면으로 부딪힌다. 그래서 **박자를 LFO로 만들었다** —
저주파 오실레이터가 게인을 여닫으면 음이 끊겨 들리고, 그게 리듬이다.

층으로 쌓이니 **음악이 곧 상태 표시가 된다.** 눈으로 보기 전에 귀로 안다.
사령관 다섯이 각자의 테마를 갖는다.

### AI 디렉터

게임이 플레이어를 읽고 **반대편으로 판을 다시 짠다.** 난이도를 올리는 게 아니다.

플레이어의 손버릇을 네 축(공격성 · 저축 · 물량 · 포탑)으로 재서 다섯 중 하나로 판정한다.

| 프로파일 | 무엇을 읽었나 |
|---|---|
| RUSHER 돌격형 | 초반에 몰아친다 |
| TURTLE 수비형 | 버티고 포탑을 올린다 |
| ECONOMIST 경제형 | 모았다 한 번에 쏟는다 |
| SWARMER 물량형 | 값싼 병력을 계속 밀어 넣는다 |
| BALANCED 균형 | 그 외 |

**사령관 다섯은 이 다섯에 얼굴을 준 것이다.** 같은 축을 사람이 읽으면 성격이 되고
기계가 읽으면 판정이 된다. 그래서 원정을 도는 것이 곧 디렉터를 한 바퀴 도는 것이다.

판정은 **결정론적이다.** `Math.random()` 을 쓰지 않는다 — 재현할 수 없으면 증거가
못 된다. 구간 경계에서만 갱신하고, 히스테리시스에 더해 **판정을 바꾼 뒤 구간 몇 개는
유지한다.** 레버가 세계를 바꾸면 지표도 따라 바뀌기 때문에, 정책이 효과를 낼 시간을
주고 나서 다시 판정하지 않으면 자기 정책의 효과에 반응해 진동한다.

**우상단 `AI` 버튼**을 누르면 디렉터 뷰가 열린다. 현재 프로파일, 판정 근거가 된
지표의 실시간 값, 다음 구간에 적용된 레버, 판정이 바뀐 이유가 뜬다.
디버그 오버레이가 아니라 **제품 기능**이다 — 제출 영상에 이 화면이 들어간다.

계층이 둘이다.

| | 무엇 | 비용 |
|---|---|---|
| 계층 1 | 런타임 디렉터. 지표 → 프로파일 → 레버 | 0ms · 로컬 · 네트워크 없음 |
| 계층 2 | 오프라인 LLM 베이크 → `data/*.json` | 빌드 시점에만. 런타임엔 읽기만 |

| | A | B |
|---|---|---|
| 역할 | **빌드 지휘** | **설계 · 검증 지휘** |

**유일한 진행 게이트**: A가 만든 것을 B가 게이트로 친다.
**B가 통과시키지 않으면 A는 다음으로 넘어갈 수 없다.**

두 사람 모두 **매일 커밋한다.** 2인 팀이므로 커밋 로그가 롤 기술서의 증거다.

## 어떻게 검증하는가

```sh
NODE_PATH=$(npm root -g) node tools/evaluate.mjs      # 전체 (20~25분)
node tools/verify-chunks.js                            # 베이크 산출물 검수
```

`tools/evaluate.mjs` 는 스모크 테스트가 아니라 **평가기**다. 성향이 다른 봇 여러 종을
사령관 다섯과 스테이지 다섯에 걸쳐 실제로 플레이시키고, 그 결과로 계약을 친다.

핵심은 **깨지면 안 되는 수치**들이다. 이건 목표가 아니라 **경계**다.

| 지켜야 할 것 | 왜 |
|---|---|
| 상성 삼각형 동수 6/6 · 동금 6/6 | 하나가 전부를 이기면 상성은 장식이다 |
| 원정 완주 봇수 0~1/8 | 봇이 완주하면 사람에겐 너무 쉽다 |
| 대조군 idle 승리 0 | 아무것도 안 해서 이기면 게임이 아니다 |
| 무뇌 도배 생존 ≤ 2전투 | 도배는 벌을 받아야 한다 |
| 결정론 · 콘솔 에러 0 · 이벤트 번호 불일치 0 | 재현할 수 없으면 증거가 못 된다 |
| 프레임 16.7ms 초과 ≤ 56 / 10800 | 래스터 예산 |

**계측기를 먼저 의심한다.** 이 저장소에서 반복적으로 값을 치른 교훈이다. 실제 사례:

- 예고 타이머를 `stepAI()` 안에서 깎았는데 그 함수는 620ms마다만 돈다.
  1000ms 예고가 **37초**가 됐고 적 스킬 사용이 0회가 됐다.
  하마터면 "적이 스킬을 안 쓴다"를 개선이라고 부를 뻔했다
- 해일 감쇠를 시전자 기지 기준으로 걸었다. 내 병력은 늘 **적 기지** 앞에 있으므로
  아무것도 안 감쇠됐고 측정값이 정확히 그대로였다
- 첫 전투에서 맞춘 곡선을 뒤 전투에 밀었다. 예측 47초, 실측 **213.9초**
- 프레임 초과의 원인을 여섯 번 틀리게 짚었다. 진짜 원인은 **결과 카드가 바뀌지도
  않으면서 매 프레임 다시 그려지던 것**이었다

성능도 가설을 세우지 않는다. 하나씩 꺼 보고 발생 프레임 번호가 움직이는지를 본다.

## ⚠️ D-3 전에 반드시 할 일

**`data/*.json` 은 현재 오프라인 자리표시자다.**

```json
{ "generator": "offline-placeholder", ... }
```

파이프라인·스키마·폴백을 실제로 통과시키기 위해 만든 것이고,
**LLM이 만든 것이 아니다.** 이대로 제출하면 "LLM이 만든 콘텐츠"는 사실이 아니게 된다.

```sh
export OPENAI_API_KEY=...          # .env 는 .gitignore 에 있다. 코드에 절대 넣지 않는다
node tools/bake.js                 # 실전 베이크 (모델은 OPENAI_MODEL 로 지정)
node tools/verify-chunks.js        # 사람이 검수. generator 필드가 제일 먼저 뜬다
```

`verify-chunks.js` 는 자리표시자를 감지하면 화면 가득 경고를 띄운다.

## 고정 제약 (전 구간 공통)

- HTML + CSS + JavaScript + Canvas 2D. **npm 없음 · 번들러 없음 · 프레임워크 없음 · 빌드 단계 없음**
- **외부 에셋 0개** — 이미지·오디오·폰트 파일 없음. 소리는 WebAudio 절차 합성
- **런타임 네트워크 호출 0회** (예외: 같은 도메인 `data/*.json`)
- `localStorage` / `sessionStorage` 사용 **0**
- API 키를 프론트엔드에 넣지 않는다. 정적 호스팅에서 프론트엔드 키는 100% 노출된다
- 판정에 `Math.random()` 금지. 틱 기반 정수 해시를 쓰고 `>>> 0` 를 빠뜨리지 않는다
  (빠뜨려서 적 스폰의 49.7%가 조용히 틀렸던 전례가 있다)
- 게임 루프 안 할당 0. 고정 타임스텝 60Hz. `render` 는 `game` 을 읽기만 한다

## 롤백 지점

git 태그를 원격에 올리려 했으나 이 저장소의 푸시 경로가 `refs/tags/*` 를 거부한다
(`refs/heads/*` 는 통과). **커밋 SHA가 그대로 롤백 지점이다.**

| 이름 | SHA | 상태 |
|---|---|---|
| `canary` | `8bdccfe` | 빈 페이지가 실제 URL에 뜬 상태 |
| `wall-jump-final` | `cf41d90` | 원버튼 벽점프 게임의 마지막 상태 |
| `runner-base` | `65dd5a1` | 3레인 러너 기본형 |
| `lane-battle` | `734ae6a` | **레인 배틀로 장르를 옮긴 지점** |

되돌아가려면 `git checkout <SHA>`.

**장르를 두 번 바꿨다.** 벽점프 → 러너 → 레인 배틀. 두 번 다 게이트는 전부
통과한 상태였고, 바꾼 이유는 게이트가 아니라 **재미없다**는 판단이었다.
판단의 근거와 그날의 측정은 `docs/ai-log.md` 에 있다.
