## 배포 URL

```
(미정) — GitHub Pages 활성화 후 이 자리에 기입한다
```

**활성화 절차 (사람이 해야 함):**

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: **`main`** / Folder: **`/ (root)`** → Save
3. 발급된 `https://roka-jsj.github.io/NHN-Game-x-AI-Hackathon/` 을 위 자리에 기입
4. **B가 자기 폰 LTE(와이파이 아님)로 접속 확인** ← 이게 되어야 배포다

이 URL은 발급된 시점부터 **성역**이다.
이후 모든 커밋은 "이 URL이 여전히 살아있는가"를 깨지 않는 선에서만 한다.

## 팀 롤

| | A | B |
|---|---|---|
| 역할 | **빌드 지휘** | **설계 · 검증 지휘** |
| 도구 | Claude Code | Codex + 베이크 스크립트 |
| 담당 | 전문가 패스 1~6 구현 지휘 / 통합 / **배포와 태그 관리(성역)** | 계층1 스펙 / 계층2 베이크 / 품질 게이트 측정 / `docs/ai-log.md` |
| 실기기 | Android + 120Hz 화면 | iPhone + LTE 회선 |

**유일한 진행 게이트**: A가 만든 패스를 B가 게이트로 친다.
**B가 통과시키지 않으면 A는 다음 패스에 들어갈 수 없다.**

두 사람 모두 **매일 커밋한다.** 2인 팀이므로 커밋 로그가 롤 기술서의 증거다.

## 저장소 구조

```
index.html          게임 진입점. 이 파일 커밋이 곧 배포다
docs/ai-log.md      AI 지휘 로그 — 실시간 기록. 문서 4종의 원재료
README.md           이 파일
```

패스가 진행되면서 `src/`, `data/`, `tools/` 가 추가된다.

## 고정 제약 (전 패스 공통)

- HTML + CSS + JavaScript + Canvas 2D. **npm 없음 · 번들러 없음 · 프레임워크 없음 · 빌드 단계 없음**
- 논리 해상도 **540 × 960** (9:16 세로 고정)
- **외부 에셋 0개** — 이미지·오디오·폰트 파일 없음. 소리는 WebAudio 절차적 합성
- **런타임 네트워크 호출 0회** (예외: 같은 도메인 `data/*.json` fetch 하나)
- API 키를 프론트엔드에 넣지 않는다. 정적 호스팅에서 프론트엔드 키는 100% 노출된다
