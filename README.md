## 어떤 게임인가

세로 화면. 좌우 벽에 발판이 교대로 붙어 있고, 아래에서 붉은 물이 차오른다.

```
누른다   → 플레이어에서 위로 흰 조준선이 뻗는다 (= 도약 거리)
          끝의 십자 조준점이 사인파로 진동한다 — 랜덤이 아니라 읽을 수 있다
뗀다     → 즉시 반대편 벽으로 도약. 지연 0프레임
착지     → 조준점이 발판 범위 안이면 붙는다. 중심 ±12% 면 완벽 착지
```

**핵심 긴장**: 정확히 겨누려면 오래 눌러야 하는데, 누르는 동안 물이 올라온다.

그리고 그 긴장이 실제로 작동하도록 **콤보가 물을 붙잡는다.**

| 연속 완벽 착지 | 물 |
|---|---|
| 0~2 | 정상 속도로 오른다 |
| **3 이상** | **멈춘다** |
| **6 이상** | **내려간다** |

정확함이 곧 생존이다. 그런데 정확하려면 오래 겨눠야 하고, 겨누는 동안 물은 오른다.
한 번만 대충 붙어도 연쇄가 끊기고 물이 다시 오른다.

- **물 추격** — 너무 앞서가면 물이 3배속으로 따라붙는다. 여전히 일정 속도라 예측 가능하다.
  깊이가 쌓일수록 추격 거리가 640px → 300px로 좁혀진다
- **발판 종류** — 보통 / 앰버(먹으면 물이 220px 내려간다) / 부서짐(0.7초 후 무너진다) /
  이동(사인파로 흔들린다. 조준 중에 **도착 순간의 위치**를 외곽선으로 보여준다)
- **한 칸 건너뛰기** — 멀리 뛰어 발판을 건너뛰면 점수와 콤보가 더 오른다
- **관문** — 발판 12개마다. 점수와 물 밀어내기

### AI 디렉터

게임이 플레이어를 읽고 **반대편으로 판을 다시 짠다.** 난이도를 올리는 게 아니다.

| 프로파일 | 판정 | 디렉터의 대응 |
|---|---|---|
| SAFE (겁쟁이) | 차지 짧고 조준 정확 | 근거리 간격을 늘려 안전지대를 걷어낸다 |
| RECKLESS (도박꾼) | 차지 길고 조준 거침 | 원거리 발판을 얇게, 보너스는 근거리에 |
| PRECISE (장인) | 차지 길고 조준 정확 | 두께 −25%, 진동 +40%, 물 +25% |
| ERRATIC (초심자) | 차지 편차 큼 | 두께 +35%, 코요테 8프레임, 진동 −50% |
| BALANCED (균형) | 그 외 | 3구간 압박 → 1구간 완화 교대 |

**우상단 `AI` 버튼**을 누르면 디렉터 뷰가 열린다.
현재 프로파일, 판정 근거가 된 지표 3개의 실시간 값, 다음 구간에 적용된 레버,
판정이 바뀐 이유, 청크 라이브러리 크기가 뜬다.
디버그 오버레이가 아니라 **제품 기능**이다 — 제출 영상에 이 화면이 들어간다.

두 사람 모두 **매일 커밋한다.** 2인 팀이므로 커밋 로그가 롤 기술서의 증거다.

런타임에 npm·번들러·빌드 단계가 개입하지 않는다.

총 페이로드 **174KB** (index 1.4KB + src 115KB + data 59KB).

## ⚠️ D-3 전에 반드시 할 일

**`data/*.json` 은 현재 오프라인 자리표시자다.**

```json
{ "generator": "offline-placeholder", ... }
```

파이프라인·스키마·폴백을 오늘 실제로 통과시키기 위해 만든 것이고,
**LLM이 만든 것이 아니다.** 이대로 제출하면 "LLM이 만든 350청크"는 사실이 아니게 된다.

```sh
export OPENAI_API_KEY=...          # .env 는 .gitignore 에 있다. 코드에 절대 넣지 않는다
node tools/bake.js                 # 실전 베이크 (모델은 OPENAI_MODEL 로 지정, 기본 gpt-4.1)
node tools/verify-chunks.js        # 사람이 검수. generator 필드가 제일 먼저 뜬다
```

`verify-chunks.js` 는 자리표시자를 감지하면 화면 가득 경고를 띄운다.

## 롤백 지점

git 태그를 원격에 올리려 했으나 이 저장소의 푸시 경로가 `refs/tags/*` 를 거부한다
(`refs/heads/*` 는 통과). **커밋 SHA가 그대로 롤백 지점이다.**

| 이름 | SHA | 상태 |
|---|---|---|
| `canary` | `8bdccfe` | 빈 페이지가 실제 URL에 뜬 상태 |
| `pass-01-core` | `73bc679` | 고정 타임스텝 · 입력 큐 · 상태 기계 |
| `pass-02-feel` | `a926133` | 히트스톱 · 입력버퍼 · 코요테 · 스쿼시 · 셰이크 |
| `pass-03-perf` | `9bafaab` | Path2D 캐시 · 루프 내 할당 0 · 유령 발판 버그 수정 |
| `pass-04-director` | `b6784ab` | 계층1 디렉터 · 콤보 · 물 추격 · 발판 종류 |
| `pass-05-art` | `02b3545` | 제도 격자 · 실루엣 테스트 · 팔레트 6색 |
| `pass-06-audio` | `16222f9` | WebAudio 절차 합성 · iOS unlock |

되돌아가려면 `git checkout <SHA>`. 로컬에서 이름을 붙이려면:

```sh
git tag canary 8bdccfe && git tag pass-01-core 73bc679 && git tag pass-02-feel a926133
git tag pass-03-perf 9bafaab && git tag pass-04-director b6784ab
git tag pass-05-art 02b3545 && git tag pass-06-audio 16222f9
git push origin --tags     # 권한이 있는 환경에서
```
