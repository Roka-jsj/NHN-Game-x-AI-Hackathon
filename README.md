## 팀 롤

| | A | B |
|---|---|---|
| 역할 | **빌드 지휘** | **설계 · 검증 지휘** |
| 도구 | Claude Code | Codex + 베이크 스크립트 |
| 담당 | 전문가 패스 1~6 구현 지휘 / 통합 / **배포와 롤백 지점 관리(성역)** | 계층1 스펙 / 계층2 베이크 / 품질 게이트 측정 / `docs/ai-log.md` |
| 실기기 | Android + 120Hz 화면 | iPhone + LTE 회선 |

**유일한 진행 게이트**: A가 만든 패스를 B가 게이트로 친다.
**B가 통과시키지 않으면 A는 다음 패스에 들어갈 수 없다.**

두 사람 모두 **매일 커밋한다.** 2인 팀이므로 커밋 로그가 롤 기술서의 증거다.

## 저장소 구조

```
index.html          게임 진입점. 이 파일 커밋이 곧 배포다
src/config.js       모든 상수 — 수치 · 팔레트 · per-step 파생값
src/main.js         루프 · 고정 타임스텝 누산기 · 입력 큐 · 캔버스 스케일링
src/game.js         시뮬레이션 — 차지 · 도약 · 착지판정 · 물 · 카메라 · 발판
src/feel.js         게임필 — 히트스톱 · 셰이크 · 스쿼시 · 파티클 · 트레일
src/render.js       드로우 — 정적 지오메트리 캐시 · 색 알파 램프 · HUD
docs/ai-log.md      AI 지휘 로그 — 실시간 기록. 문서 4종의 원재료
tools/smoke.mjs     헤드리스 검증 하네스 (개발 전용)
```

**`tools/` 는 게임이 절대 로드하지 않는다.** 브라우저는 `index.html` 과 `src/` 만 본다.
런타임에 npm·번들러·빌드 단계가 개입하지 않는다는 제약은 그대로다.

## 롤백 지점

git 태그를 원격에 올리려 했으나 이 저장소의 푸시 경로가 `refs/tags/*` 를 거부한다
(`refs/heads/*` 는 통과). **커밋 SHA가 그대로 롤백 지점이다.**

| 이름 | SHA | 상태 |
|---|---|---|
| `canary` | `8bdccfe` | D-9 · 빈 페이지가 실제 URL에 뜬 상태 |
| `pass-01-core` | `73bc679` | 고정 타임스텝 · 입력 큐 · 상태 기계 |
| `pass-02-feel` | `a926133` | 히트스톱 · 입력버퍼 · 코요테 · 스쿼시 · 셰이크 |

되돌아가려면 `git checkout <SHA>`.
로컬에서 이름을 붙이고 싶으면 한 번에 만들 수 있다:

```sh
git tag canary 8bdccfe
git tag pass-01-core 73bc679
git tag pass-02-feel a926133
git push origin --tags     # 권한이 있는 환경에서
```

| # | 항목 | 측정 주체 | 현황 |
|---|---|---|---|
| 1 | 60Hz vs 120Hz 속도 동일 | 헤드리스 | **통과** — 도달 발판 45/45 (오차 0.00%) |

| 4 | 입력 지연 ≤1프레임 | 코드 레벨 통과 / **실기기 녹화 필요** | 큐가 프레임 시작에서 소비됨 확인 |

| 7 | 첫 로딩 ≤2초 (LTE) | **사람** | 미측정 |
| 8 | 콘솔 청결 | 헤드리스 | **통과** — 에러·경고 0 |
